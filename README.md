## Featured projects

### [RootSignal](https://github.com/vidit-16/RootSignal)
Root-cause analytics for sales and supply operations. It traces metric movements to the segments behind them, separates performance changes from mix effects, estimates business impact, and produces evidence-backed investigation signals.

**Python · Pandas · NumPy · SQL · Streamlit · Plotly · pytest**

### [BaseDrift](https://github.com/vidit-16/BaseDrift)
A pre-authorization decision layer for outbound payments. Combines deterministic policy rules with an LLM semantic layer, with a strong emphasis on authorization provenance, fail-safe handling, auditability, and adversarial testing.

**Python · FastAPI · LLMs · Webhooks · MCP · pytest**

### [Wordle Solver](https://github.com/vidit-16/WordleSolver)
Compares constraint-based reasoning with information-theoretic optimization, including Wordle-accurate feedback handling and entropy-based guess selection.

**Python · Pandas · Streamlit · Information Theory**

### [Food Vision](https://github.com/vidit-16/foodVision)
A computer-vision inference API built around a ResNet-50 classifier, exposed through FastAPI and packaged with Docker for reproducible deployment.

**Python · PyTorch · ResNet-50 · FastAPI · Docker**

### [DesiMacros](https://github.com/vidit-16/DesiMacros)
A conversational nutrition tracker for Indian diets that turns free-form meal descriptions into structured food entries and combines nutrition lookup with rule-based insights.

**Python · FastAPI · Streamlit · SQLAlchemy · PostgreSQL · LLMs**
